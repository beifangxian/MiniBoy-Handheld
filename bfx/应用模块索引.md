# 应用模块索引

总览：[项目架构表](项目架构表.md)

本项目的六个独立 ESP-IDF 应用分别对应以下文档：

- [launcher](应用适配层/launcher.md)：启动器、ROM 浏览、主题、存档和应用切换
- [retro-core](应用适配层/retro-core.md)：NES、SNES、GB、GBC、PCE、SMS、G&W、Lynx
- [prboom-go](应用适配层/prboom-go.md)：DOOM / Doom II
- [gwenesis](应用适配层/gwenesis.md)：Sega Mega Drive / Genesis
- [fmsx](应用适配层/fmsx.md)：MSX 和 DSK 磁盘镜像
- [txt-reader](应用适配层/txt-reader.md)：TXT 电子书阅读器

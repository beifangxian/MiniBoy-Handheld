# 新手复刻指南

[返回知识点清单](知识点清单.md) | [项目架构表](项目架构表.md) | [板级适配层](板级适配层/板级适配层.md) | [硬件模块索引](驱动层/硬件模块索引.md)

本指南用于从零复刻当前 Retro-Go Chaeng 项目。建议先复刻与项目一致的硬件，确认原版固件能够运行后，再修改功能或更换硬件。

## 1. 准备硬件

尽量使用与当前目标一致的硬件：

- ESP32-S3
- 320×240 ST7789 屏幕
- SPI SD 卡
- I2S 外部 DAC 或功放
- GPIO 按键
- 电池 ADC 分压电路
- WS2812 RGB 灯

GPIO 和接口以以下文档为准：

- [板级适配层](板级适配层/板级适配层.md)
- [硬件模块索引](驱动层/硬件模块索引.md)
- [T320-S3 目标说明](../components/retro-go/targets/t320-s3/docs/README.md)

板级配置文件：

```text
components/retro-go/targets/t320-s3/config.h
components/retro-go/targets/t320-s3/env.py
components/retro-go/targets/t320-s3/sdkconfig
```

如果硬件 GPIO 或芯片型号不同，不能直接使用 `t320-s3` 配置，需要新建目标目录并修改这些文件。

## 2. 准备软件环境

Windows 下安装：

1. ESP-IDF 5.5.5
2. Python
3. ESP32-S3 USB 串口驱动
4. Git

打开 ESP-IDF Terminal，从项目根目录进入：

```bat
cd /d E:\ESP\esp_fork\retro-go_chaeng
```

必须确认 `IDF_PATH` 已设置。可以在终端执行：

```bat
echo %IDF_PATH%
```

不要使用普通 `idf.py build` 代替项目构建工具。本项目包含多个独立应用，需要使用根目录的 `rg_tool.py`。

## 3. 编译完整固件

普通编译：

```bat
python rg_tool.py --target=t320-s3 build-img
```

干净重编译：

```bat
python rg_tool.py --target=t320-s3 release
```

编译过程会依次处理：

1. launcher
2. retro-core
3. prboom-go
4. gwenesis
5. fmsx
6. txt-reader
7. Bootloader 和完整镜像

输出文件：

```text
retro-go_chaeng_t320-s3.img
```

## 4. 烧录 ESP32-S3

确认 ESP32-S3 的串口号，例如 `COM3`，执行：

```bat
python rg_tool.py --target=t320-s3 --port=COM3 install
```

`install` 会自动编译、打包并烧录完整镜像。

如果设备无法连接：

1. 按住 BOOT 键。
2. 按一下 RESET 键。
3. 松开 BOOT 键。
4. 再次执行烧录命令。

也可以手动烧录已有镜像：

```bat
esptool.py --chip esp32s3 --port COM3 write_flash --flash_size detect 0x0 retro-go_chaeng_t320-s3.img
```

## 5. 准备 SD 卡

SD 卡建议建立以下目录：

```text
roms/
  nes/
  snes/
  gb/
  gbc/
  md/
  doom/
  msx/
  txt/

bios/
  msx/

saves/
covers/
themes/
```

资源对应关系：

| 资源 | 目录 | 应用 |
|---|---|---|
| NES、SNES、GB 等 | `roms/nes`、`roms/snes`、`roms/gb` | [retro-core](应用适配层/retro-core.md) |
| Mega Drive | `roms/md` | [gwenesis](应用适配层/gwenesis.md) |
| DOOM WAD | `roms/doom` | [prboom-go](应用适配层/prboom-go.md) |
| MSX ROM、DSK | `roms/msx` | [fMSX](应用适配层/fmsx.md) |
| TXT 书籍 | `roms/txt` | [TXT Reader](应用适配层/txt-reader.md) |
| MSX BIOS | `bios/msx` | [fMSX](应用适配层/fmsx.md) |

## 6. 第一次运行验证

烧录完成后依次验证：

1. 设备能否正常上电进入 launcher。
2. 屏幕方向、颜色和背光是否正常。
3. 按键是否全部有响应。
4. SD 卡是否能被识别。
5. ROM 和 TXT 文件是否出现在菜单中。
6. 模拟器是否有声音。
7. 存档、恢复和返回 launcher 是否正常。
8. RGB 灯和电池电量显示是否正常。

查看串口日志：

```bat
python rg_tool.py --target=t320-s3 --port=COM3 monitor launcher
```

## 7. 单独调试应用

完整镜像成功运行后，可以只编译或烧录某个应用来加快开发：

```bat
python rg_tool.py --target=t320-s3 build launcher
python rg_tool.py --target=t320-s3 --port=COM3 flash launcher
python rg_tool.py --target=t320-s3 --port=COM3 monitor launcher
```

也可以把 `launcher` 换成 `retro-core`、`prboom-go`、`gwenesis`、`fmsx` 或 `txt-reader`。

## 8. 更换硬件时的步骤

如果不是复刻原始 T320-S3 硬件，建议按以下顺序处理：

1. 复制 `components/retro-go/targets/t320-s3/` 目录。
2. 重命名为新的目标名称。
3. 修改 `config.h` 中的 GPIO、屏幕和音频配置。
4. 修改 `env.py` 中的芯片型号和镜像信息。
5. 准备对应的 `sdkconfig`。
6. 使用新的 `--target` 编译。
7. 先验证屏幕、按键、SD 卡和音频，再运行模拟器。

## 9. 新手学习顺序

1. 先理解 [项目架构表](项目架构表.md)。
2. 阅读 [板级适配层](板级适配层/板级适配层.md)，确认硬件映射。
3. 阅读 [用户交互层](用户交互层/用户交互层.md)，理解 launcher。
4. 阅读 [应用适配层](应用适配层/应用适配层.md)，理解模拟器如何启动。
5. 阅读 [公共运行时层](公共运行时层/公共运行时层.md)，理解 `rg_*` 接口。
6. 最后阅读 [驱动层](驱动层/驱动层.md) 和 [平台层](平台层/平台层.md)。

常见错误：

- ESP-IDF 版本不匹配。
- 忘记指定 `--target=t320-s3`。
- 直接使用普通 `idf.py flash`。
- GPIO 与实际接线不一致。
- SD 卡目录或 BIOS 文件位置错误。
- 修改 `sdkconfig` 后没有清理应用构建目录。

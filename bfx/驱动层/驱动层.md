# 驱动层

## 层级职责

驱动层负责把公共运行时接口转换为 ESP32-S3 外设操作，主要处理：

- SPI 屏幕通信
- I2S 音频输出
- GPIO 按键和控制信号
- ADC 电池采样
- RMT WS2812 时序
- SD 卡 SPI 总线

公共运行时负责功能调度，驱动层负责具体硬件通信。

## 主要实现

| 硬件 | 驱动文件 | 公共入口 |
|---|---|---|
| ST7789/ILI9341 屏幕 | [`drivers/display/ili9341.h`](../../components/retro-go/drivers/display/ili9341.h) | [`rg_display.c`](../../components/retro-go/rg_display.c) |
| I2S 扬声器 | [`drivers/audio/i2s.c`](../../components/retro-go/drivers/audio/i2s.c) | [`rg_audio.c`](../../components/retro-go/rg_audio.c) |
| WS2812 | [`drivers/led/ws2812.c`](../../components/retro-go/drivers/led/ws2812.c) | `rg_system.c`、GUI 状态指示 |
| GPIO 按键 | ESP-IDF GPIO + `rg_input.c` | [`rg_input.c`](../../components/retro-go/rg_input.c) |
| 电池 ADC | ESP-IDF ADC + `rg_input.c` | [`rg_input.c`](../../components/retro-go/rg_input.c) |
| SD 卡 SDSPI | ESP-IDF SDSPI + `rg_storage.c` | [`rg_storage.c`](../../components/retro-go/rg_storage.c) |

## 接口原则

- GPIO 编号、SPI 主机、音频引脚和屏幕参数由 [板级适配层](../板级适配层/板级适配层.md) 提供。
- 驱动通过 ESP-IDF 外设 API 工作。
- 上层应用不应直接访问 GPIO、SPI、I2S 或 RMT。
- 新增硬件时，先在目标配置中定义能力，再在驱动层实现通信。

## 修改入口

- 修改屏幕初始化序列：查看目标 `config.h` 的 `RG_SCREEN_INIT()` 和 `drivers/display/ili9341.h`。
- 修改音频格式或 I2S 引脚：查看 `drivers/audio/i2s.c` 和目标配置。
- 修改按键电平、ADC 通道：查看 `rg_input.c` 和目标配置。
- 修改 WS2812 编码时序：查看 `drivers/led/ws2812.c`。
- 修改 SD 卡挂载和读写：查看 `rg_storage.c`。

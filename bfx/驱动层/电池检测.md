# 电池检测

[返回知识点清单](../知识点清单.md) | [硬件模块索引](硬件模块索引.md) | [按键](按键.md) | [RGB 灯](RGB灯.md)

## 1. 硬件功能

电池电压通过分压电路连接到 ESP32-S3 的 ADC，用于显示电量百分比和低电量提示。

## 2. ADC 配置

| 项目 | 配置 |
|---|---|
| 输入 GPIO | GPIO4 |
| ADC 单元 | ADC1 |
| ADC 通道 | ADC1_CH3 |
| 电压换算 | 原始测量值乘以 2 |
| 满电参考 | 约 4.15 V |
| 低电量参考 | 约 3.50 V |

配置位于 [`components/retro-go/targets/t320-s3/config.h`](../../components/retro-go/targets/t320-s3/config.h)：

```c
#define RG_BATTERY_DRIVER 1
#define RG_BATTERY_ADC_UNIT ADC_UNIT_1
#define RG_BATTERY_ADC_CHANNEL ADC_CHANNEL_3
```

## 3. 软件实现

主要代码位于 [`components/retro-go/rg_input.c`](../../components/retro-go/rg_input.c)：

- 读取 ADC 原始值
- 使用 ESP-IDF ADC 校准数据换算电压
- 计算电池百分比
- 向系统提供电量和电压信息
- 在显示层触发低电量指示

目标配置中的计算宏：

```c
#define RG_BATTERY_CALC_PERCENT(raw) (((raw) * 2.f - 3500.f) / (4150.f - 3500.f) * 100.f)
#define RG_BATTERY_CALC_VOLTAGE(raw) ((raw) * 2.f * 0.001f)
```

## 4. 系统显示

显示层会根据系统低电量状态绘制电池提示。相关逻辑位于 [`components/retro-go/rg_display.c`](../../components/retro-go/rg_display.c)，系统状态管理位于 [`components/retro-go/rg_system.c`](../../components/retro-go/rg_system.c)。

## 5. 修改位置

- 修改 ADC GPIO、通道或换算公式：`targets/t320-s3/config.h`。
- 修改 ADC 读取和校准：`components/retro-go/rg_input.c`。
- 修改低电量图标：`components/retro-go/rg_display.c`。

相关：[ADC 接口知识](../知识点清单.md#adc)。

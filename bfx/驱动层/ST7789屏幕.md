# ST7789 屏幕

[返回知识点清单](../知识点清单.md) | [硬件模块索引](硬件模块索引.md) | [SD 卡](SD卡.md) | [扬声器](扬声器.md)

## 1. 硬件功能

当前 T320-S3 使用 3.2 英寸 ST7789 IPS 屏幕，分辨率为 320×240，使用 SPI 连接 ESP32-S3。

## 2. GPIO 和接口

| 信号 | GPIO |
|---|---:|
| SPI MOSI | 12 |
| SPI CLK | 48 |
| Chip Select | 14 |
| Data/Command | 47 |
| Reset | 3 |
| 背光 | 39 |
| MISO | 未连接 |

配置位置：[`components/retro-go/targets/t320-s3/config.h`](../../components/retro-go/targets/t320-s3/config.h)。

关键配置：

```c
#define RG_SCREEN_DRIVER 0
#define RG_SCREEN_HOST SPI2_HOST
#define RG_SCREEN_SPEED SPI_MASTER_FREQ_40M
#define RG_SCREEN_WIDTH 320
#define RG_SCREEN_HEIGHT 240
#define RG_SCREEN_ROTATION 5
#define RG_SCREEN_RGB_BGR 0
```

## 3. 驱动结构

- [`components/retro-go/rg_display.c`](../../components/retro-go/rg_display.c)：显示初始化、Surface 刷新、旋转、缩放、背光和脏区域更新。
- [`components/retro-go/drivers/display/ili9341.h`](../../components/retro-go/drivers/display/ili9341.h)：ILI9341/ST7789 SPI 命令和底层传输。
- `RG_SCREEN_INIT()`：位于目标 `config.h`，保存屏幕初始化命令序列。

## 4. 画面流程

1. 应用创建 `rg_surface_t`。
2. 模拟器或 GUI 绘制到 Surface。
3. `rg_display_submit()` 提交更新区域。
4. `rg_display.c` 根据旋转、缩放和安全区域计算窗口。
5. SPI 将像素数据发送到 ST7789。

## 5. 修改位置

- 修改 GPIO、分辨率、旋转或颜色顺序：编辑 `targets/t320-s3/config.h`。
- 修改刷新、缩放或背光逻辑：编辑 `rg_display.c`。
- 修改 ST7789 命令：编辑 `RG_SCREEN_INIT()` 或 `ili9341.h`。

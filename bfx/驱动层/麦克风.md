# 麦克风

[返回知识点清单](../知识点清单.md) | [硬件模块索引](硬件模块索引.md) | [扬声器](扬声器.md) | [SD 卡](SD卡.md)

## 1. 硬件配置

当前硬件已安装 InvenSense ICS-43434 数字 MEMS 麦克风，使用 I2S 接口：

| 信号 | GPIO |
|---|---:|
| WS / LRCK | GPIO1 |
| SCK / BCLK | GPIO2 |
| SD / 数据输出 | GPIO21 |
| LR / 声道选择 | GND（左声道） |

麦克风的 LR 接地，固件配置为读取左声道。板级引脚定义见 [`components/retro-go/targets/t320-s3/config.h`](../../components/retro-go/targets/t320-s3/config.h)。

## 2. 当前状态

- AI 语音功能在启动器和 TXT 阅读器中启用：同时按住 A+B 开始录音，松开任一键结束并上传。
- 采集使用 I2S RX，16 kHz、单声道、16-bit PCM/WAV；最长录音 15 秒。
- TXT 阅读器的请求会附带当前页文字；回复以文字显示，较长回复可用方向键滚动查看。
- 扬声器仍使用独立的 I2S TX，见 [`components/retro-go/drivers/audio/i2s.c`](../../components/retro-go/drivers/audio/i2s.c)。

## 3. API 配置

在 SD 卡 `/sd/retro-go/config/ai.conf` 配置接口地址、API Key、语音识别模型和聊天模型，必须使用 HTTPS。统一调用 `/audio/transcriptions`（multipart WAV 上传）+ `/chat/completions`，通过 `transcription_model` 区分转写模型：

- OpenAI：`whisper-1`。
- 智谱：`glm-asr-2512`（新版 ASR 接口，与 OpenAI multipart 格式一致）。

配置示例与字段说明见 [`README.md`](../../README.md#语音-ai-配置)。API Key 以明文保存在 SD 卡，应保护存储介质并使用限额、可撤销的密钥。

# 按键

[返回知识点清单](../知识点清单.md) | [硬件模块索引](硬件模块索引.md) | [电池检测](电池检测.md) | [ST7789 屏幕](ST7789屏幕.md)

## 1. 硬件功能

T320-S3 使用 GPIO 按键，按下时为低电平，释放时通过内部上拉保持高电平。

## 2. GPIO 映射

| 功能 | GPIO |
|---|---:|
| BOOT / MENU | 0 |
| MENU | 18 |
| OPTION | 8 |
| SELECT | 16 |
| START | 17 |
| A | 15 |
| B | 5 |
| LEFT | 19 |
| RIGHT | 6 |
| UP | 7 |
| DOWN | 20 |

配置位于 [`components/retro-go/targets/t320-s3/config.h`](../../components/retro-go/targets/t320-s3/config.h) 的 `RG_GAMEPAD_GPIO_MAP`。

## 3. 软件实现

主要代码位于 [`components/retro-go/rg_input.c`](../../components/retro-go/rg_input.c)：

- 初始化 GPIO 输入和内部上拉
- 读取按键电平
- 将 GPIO 映射为 `RG_KEY_*` 逻辑按键
- 处理 ADC 按键和 GPIO 按键
- 为应用提供统一的 `rg_input_read_gamepad()` 接口

应用不直接读取 GPIO，而是使用统一的逻辑按键值。

## 4. 应用使用

- launcher 使用方向键、MENU、OPTION、START 和 SELECT 操作菜单。
- 模拟器将 A、B、方向键转换为对应主机手柄输入。
- 游戏菜单通常由 `RG_KEY_MENU` 打开。
- 模拟器选项通常由 `RG_KEY_OPTION` 打开。
- TXT 阅读器使用 A/B 翻页，SELECT/START 调节字号。

## 5. BOOT 和恢复功能

`GPIO0` 同时连接 BOOT/恢复功能和 MENU 逻辑。目标配置中：

```c
#define RG_RECOVERY_BTN RG_KEY_MENU
```

上电或复位时按住指定按键可进入恢复相关流程，正常运行时仍作为 MENU 输入使用。

## 6. 修改位置

- 修改 GPIO 或按键极性：`targets/t320-s3/config.h`。
- 修改按键读取、滤波或逻辑映射：`components/retro-go/rg_input.c`。
- 修改应用内按键行为：对应应用的 `main.c` 或输入适配文件。

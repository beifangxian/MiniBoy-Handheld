# 扬声器

[返回知识点清单](../知识点清单.md) | [硬件模块索引](硬件模块索引.md) | [ST7789 屏幕](ST7789屏幕.md) | [RGB 灯](RGB灯.md)

## 1. 硬件功能

扬声器通过外部 I2S DAC 接收数字音频。Retro-Go 的公共音频层为启动器和所有模拟器提供统一音频接口。

## 2. GPIO 和接口

| 信号 | GPIO |
|---|---:|
| I2S DATA / DOUT | 40 |
| I2S BCLK | 41 |
| I2S LRCK / WS | 42 |

配置位于 [`components/retro-go/targets/t320-s3/config.h`](../../components/retro-go/targets/t320-s3/config.h)：

```c
#define RG_AUDIO_USE_INT_DAC 0
#define RG_AUDIO_USE_EXT_DAC 1
#define RG_GPIO_SND_I2S_BCK 41
#define RG_GPIO_SND_I2S_WS 42
#define RG_GPIO_SND_I2S_DATA 40
```

## 3. 软件实现

- [`components/retro-go/rg_audio.c`](../../components/retro-go/rg_audio.c)：音频设备选择、音量、静音、滤波和音频队列。
- [`components/retro-go/drivers/audio/i2s.c`](../../components/retro-go/drivers/audio/i2s.c)：ESP-IDF I2S 驱动初始化、引脚设置和数据输出。
- `drivers/audio/buzzer.c`：蜂鸣器输出，当前目标未启用。

`rg_audio.c` 根据编译宏注册 I2S、内部 DAC、蜂鸣器和 SDL 等音频设备，并让应用通过 `rg_audio_submit()` 提交采样数据。

## 4. 应用连接

- 模拟器核心生成音频采样。
- 应用适配层调用 `rg_audio_submit()`。
- `rg_audio.c` 进行音量、滤波和设备管理。
- `i2s.c` 将 PCM 数据发送到外部 DAC。

## 5. 修改位置

- 修改音频 GPIO：`targets/t320-s3/config.h`。
- 修改 I2S 初始化或数据格式：`drivers/audio/i2s.c`。
- 修改音量、滤波和设备菜单：`rg_audio.c`。
